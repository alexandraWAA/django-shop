============================================================
СКРИНШОТ 1: Импорт моделей и создание категорий
============================================================
>>> from catalog.models import Category, Product
>>>
>>> cat1 = Category.objects.create(name='Электроника', description='Смартфоны, ноутбуки, планшеты')
>>> cat2 = Category.objects.create(name='Одежда', description='Мужская и женская одежда')
>>> cat3 = Category.objects.create(name='Дом и сад', description='Товары для дома и дачи')
>>>
>>> print("✅ Категории созданы:")
✅ Категории созданы:
>>> print(Category.objects.all())
<QuerySet [<Category: Электроника>, <Category: Одежда>, <Category: Дом и сад>]>

============================================================
СКРИНШОТ 2: Создание продуктов
============================================================
>>> electronics = Category.objects.get(name='Электроника')
>>> clothing = Category.objects.get(name='Одежда')
>>>
>>> product1 = Product.objects.create(
...     name='iPhone 15 Pro',
...     description='Флагманский смартфон Apple',
...     price=999.00,
...     category=electronics
... )
>>>
>>> product2 = Product.objects.create(
...     name='Samsung Galaxy S24',
...     description='Мощный Android-смартфон',
...     price=899.00,
...     category=electronics
... )
>>>
>>> product3 = Product.objects.create(
...     name='Джинсы классические',
...     description='Удобные джинсы из хлопка',
...     price=79.99,
...     category=clothing
... )
>>>
>>> print("✅ Продукты созданы:")
✅ Продукты созданы:
>>> print(Product.objects.all())
<QuerySet [<Product: iPhone 15 Pro ($999.00)>, <Product: Samsung Galaxy S24 ($899.00)>, <Product: Джинсы классические ($79.99)>]>

============================================================
СКРИНШОТ 6: Обновление цены продукта
============================================================
>>> product_to_update = Product.objects.get(name='iPhone 15 Pro')
>>> print(f"До: {product_to_update.name} = ${product_to_update.price}")
До: iPhone 15 Pro = $999.00
>>> product_to_update.price = 849.00
>>> product_to_update.save()
>>> product_updated = Product.objects.get(name='iPhone 15 Pro')
>>> print(f"После: {product_updated.name} = ${product_updated.price}")
После: iPhone 15 Pro = $849.00

============================================================
